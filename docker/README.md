# Supabase Docker

This is a minimal Docker Compose setup for self-hosting Supabase. Follow the steps [here](https://supabase.com/docs/guides/hosting/docker) to get started.

# Docker Backup Installation
Run the script `supabase-db-backup.sh` to create a backup of the database content as sql dump file.
Run the script `supabase-db-restore.sh` to load the database content into supabase.
